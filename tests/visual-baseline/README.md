# Visual baseline

Phase 1 captures the existing landing, lobby, game board, dialogs, result, and
leaderboard views at their supported breakpoints before provider replacement.
Images in this directory are reference artifacts only and must not contain
access tokens, wallet secrets, tickets, or personal data.

The baseline is generated from the unchanged `apps/web` sources after the
workspace move. Any later approved identity or account-coin copy change must be
recorded explicitly rather than accepted as a blanket pixel-diff update.
